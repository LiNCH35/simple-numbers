# Перенос параметров между масштабами (generalization)

Сгенерировано scripts/generalization.mjs, 2026-11-07T06:58:53.387Z.

Процедура подбора (для каждого масштаба X отдельно): координатный спуск — бисекция по kappa (цель — twinIndex реальных на том же отрезке [2, X]) при k = 1/disp реальных; затем обновление k по измеренной дисперсии модели; затем повторная бисекция kappa. Проверка переноса: те же параметры применяются к прогонам других масштабов без перенастройки. Отклонение <= ~3% (порядок sd по сидам) считаем переносом.

detrended rho1: вычтено среднее промежутков в 20 лог-бинах по x — контроль на артефакт нестационарности (средний промежуток растёт как ln x). CI — блоковый бутстрап (200 ресемплов, блок 50000 промежутков, MBB).
