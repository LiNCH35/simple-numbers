# Условная модель P(g | x, g_prev, r mod 30)

Сгенерировано scripts/markov-model.mjs, 2026-11-06T20:25:37.423Z.

Механика: следующий промежуток — гамма со средним ln x · (1 + beta·(1 − g_prev/ln x)) (ручка антикорреляции beta); с вероятностью min(kappa/ln x, 0.9) и только из twin-классов r mod 30 ∈ {11, 17, 29} промежуток = 2 (ручка kappa); гамма-форма k (ручка сгущений); безпараметрический residue-шаг: raw-промежуток округляется к ближайшему чётному g', для которого (r + g') mod 30 разрешён (адаптивная компенсация плотности по скользящему смещению). В отличие от lattice30 нет перенаправления +2 — баланс вычетов не задаётся правилом, а получается из распределения.
