# Simple Numbers

Интерактивное веб-приложение на Vue.js для исследования простых чисел и вероятностных алгоритмов. Приложение позволяет генерировать последовательности простых чисел с использованием вероятностных методов и анализировать их распределение.

## Обзор

Simple Numbers - это экспериментальный инструмент, который реализует уникальный подход к генерации простых чисел на основе вероятностных вычислений. Основная идея заключается в использовании вероятностных функций для определения следующего простого числа в последовательности.

## Основные возможности

- **Генерация простых чисел**: Использует вероятностные алгоритмы для нахождения следующих простых чисел
- **Вычисление вероятностей**: Расчет вероятности нахождения простого числа на основе существующей последовательности
- **Интерактивный интерфейс**: Реальное время отображение результатов и параметров
- **Настройка алгоритма**: Возможность изменения чувствительности и других параметров
- **Режимы генерации**: Пошаговая и автоматическая генерация последовательностей

## Алгоритм работы

### Основные функции

1. **calculateProbability()**: Основной метод вычисления вероятности нахождения следующего простого числа
2. **getProbabilityFromCache()**: Оптимизированный метод с использованием кэша для быстрого получения вероятности
3. **addProbabilityContributions()**: Добавляет вклады для нового простого числа в существующую последовательность
4. **getNextSimple()**: Генерирует следующее простое число в последовательности
5. **getNextSimpleByStep()**: Пошаговая генерация с проверкой
6. **getList()**: Генерирует полную последовательность заданной длины

### Математическая основа

Вероятность вычисляется по формуле включения-исключения с использованием оптимизированного кэширования:

Для двух простых чисел (2, 3):
```
P = 1 - (1/2 + 1/3 - 1/2×1/3)
```

Для трёх простых чисел (2, 3, 5):
```
P = 1 - (1/2 + 1/3 + 1/5 - 1/2×1/3 - 1/2×1/5 - 1/3×1/5 + 1/2×1/3×1/5)
```

Общая формула:
```
P = 1 - Σ(±1/(p₁ × p₂ × ... × pₙ))
```

Где:
- p₁, p₂, ..., pₙ - простые числа из текущей последовательности
- Знак определяется количеством множителей: нечётное количество → положительный знак, чётное количество → отрицательный знак
- Параметр `sensitivity` ограничивает максимальное количество множителей в слагаемых

### Оптимизация производительности

Приложение использует кэширование для оптимизации вычислений:

- **Инициализация кэша**: При первом вызове вычисляются все возможные комбинации произведений
- **Инкрементальные обновления**: При добавлении нового простого числа вычисляются только новые комбинации
- **Автоматический сброс**: Кэш сбрасывается при изменении параметра `sensitivity`

Это позволяет избежать повторных вычислений и значительно ускоряет работу с большими последовательностями простых чисел.

## Параметры конфигурации

- **logs**: Включение/выключение логирования в консоль
- **requiredInInterval**: Режим генерации в заданном интервале (по умолчанию: true)
- **sensitivity**: Чувствительность алгоритма (по умолчанию: 5)
- **maxSimples**: Максимальное количество простых чисел для генерации
- **sequenceCount**: Количество последовательностей для множественной генерации (по умолчанию: 3)

## Использование

1. Откройте приложение в браузере после запуска dev сервера
2. Используйте кнопки для управления генерацией:
   - `calculateProbability` - вычислить текущую вероятность
   - `getNextSimple` - получить следующее простое число
   - `getNextSimpleByStep` - пошаговая генерация
   - `getList` - сгенерировать полную последовательность
   - `generateMultiple` - сгенерировать несколько последовательностей для сравнения
   - `drawDistributionChart` - показать график распределения разниц
3. Настройте параметры с помощью чекбоксов и полей ввода:
   - **logs**: включить детальное логирование вычислений
   - **requiredInInterval**: режим генерации в вероятностном интервале
   - **sensitivity**: ограничение сложности вычислений (рекомендуется 5)
   - **maxSimples**: максимальное количество чисел в последовательности
   - **sequenceCount**: количество последовательностей для множественной генерации (от 1 до 10)
4. Наблюдайте за результатами в реальном времени, включая текущую вероятность и сгенерированную последовательность

### График распределения

Приложение включает визуализацию разницы между псевдопростыми и настоящими простыми числами:

- **Ось X**: Натуральные числа с шагом 5
- **Ось Y**: Разница (псевдопростые - настоящие простые)
- **Цветовые линии**: Каждая последовательность отображается своим цветом
- **Легенда**: Показывает соответствие цветов номерам последовательностей
- **Сравнительный анализ**: Позволяет оценить стабильность алгоритма

### Множественная генерация

Функция `generateMultiple` позволяет создать от 1 до 10 независимых последовательностей для статистического анализа:

1. **Независимые прогоны**: Каждая последовательность генерируется с нуля
2. **Сравнительный график**: Все последовательности отображаются на одном графике
3. **Автоматическое масштабирование**: Ось Y подстраивается под реальные значения разниц
4. **Цветовая дифференциация**: Уникальный цвет для каждой последовательности
